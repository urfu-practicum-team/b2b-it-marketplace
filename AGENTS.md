# B2B-маркетплейс ИТ-услуг

Компании публикуют задания и выбирают исполнителей с подтверждённой квалификацией. По требованиям проекта оплата резервируется до приёмки результата. При работе над функцией сверяй сценарий и критерии приёмки с [требованиями](docs/requirements.md).

## Где вносить изменения

- **Интерфейс.** Код приложения на React и Vite находится в `frontend/src/`. В `docs/interface/` лежат HTML-макеты. При разработке и проверке экранов используй [правила дизайна](DESIGN.md).
- **Архитектура сервера.** При разработке и ревью определи владельца операции и таблиц по разделу 3 [описания компонентов](docs/design/components.md). Размещай классы в пакетах соответствующих подмодулей и используй репозитории Spring Data JPA для работы с их таблицами.
- **API.** Контроллеры Spring находятся в `backend/src/main/java/ru/urfu/marketplace/`. Проектный контракт описывает в том числе запланированные операции. При интеграции клиента проверяй наличие обработчика в коде. [Контракт OpenAPI](docs/design/openapi.yaml)
- **База данных.** Flyway применяет миграции из `backend/src/main/resources/db/migration/`. В `docs/design/db/migration/` хранятся проектные SQL-файлы, в том числе для будущих этапов. Назначение таблиц и связи описаны в [модели данных](docs/design/erd.md).

## Сборка и проверка

- **Сервер.** Сборка с JDK 21 — `mvn -f backend/pom.xml package`. Для интеграционных тестов выполни `mvn -f backend/pom.xml verify` с работающим Docker. Testcontainers поднимет отдельный PostgreSQL.
- **Клиент.** В каталоге `frontend/` выполни `npm ci`, затем `npm run build`. Поддерживаемые версии Node.js указаны в `frontend/package.json`.
- **Приложение целиком.** Перед первым запуском подготовь пароли и каталог портфолио по [README](README.md). Из корня выполни `docker compose up -d --build --wait`. При стандартном порте открой `http://localhost:8081/` и проверь ответ `http://localhost:8081/api/v1/health` через Nginx.
- **Стенд.** Порядок выкладки и проверки развёртывания описан в [документации стенда](docs/deployment.md).
