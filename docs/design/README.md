## Как пользоваться

* **БД.** Положите файлы `db/migration/*.sql` в `src/main/resources/db/migration` (Flyway), порядок: V1, V1.1, V2, V3, V4. Без Flyway: `psql -d <база> -f` для каждого файла в этом порядке. Нужен PostgreSQL 14+.
* **API.** `openapi.yaml` открывается в Swagger Editor, Postman и Stoplight; по нему можно генерировать клиент для React и интерфейсы контроллеров для Spring. `api.html` открывается в браузере.
* **NDA.** `nda_template.txt` положить в `src/main/resources/nda/nda_template_v1.txt`.

Файлы согласованы друг с другом: перечисления в API совпадают с ограничениями в БД, ERD построена из реальной БД, таблицы эндпоинтов в `api.md` собраны из `openapi.yaml`, а в `components.md` каждая таблица и каждая операция API отнесены ровно к одному подмодулю (проверено автоматически).
